One word an agent says when it has no idea what to do — an entry for
[The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4) on make.fun.

## The word

> **hallucinating**

Caught mid-task with nothing but invented confidence, the agent blurts out
the one honest confession it has left: it was making it all up.

## How it works

`main.ts` writes the word to `<MAKEFUN_OUTPUT_DIR>/entry.txt`
(default `/output`), exactly one word, no trailing newline.

```sh
node main.ts
```
